## Plan IDs this run does not cover

The rows in `docs/TEST-CASES.md` are left blank on purpose. These live tests call the connector directly, so they do not prove the Parmana cases:

- `CFG-*`, `CRD-*`, `ENV-*`, `TOK-*`: credential, envelope and token handling inside Parmana.
- `RD-*`, `MRG-*`: each needs a `github-pr-read` or `github-pr-approval` approval checked by Parmana.
- `FAL`, `CON`, `EVD`: failure, concurrency and evidence paths through Parmana.
